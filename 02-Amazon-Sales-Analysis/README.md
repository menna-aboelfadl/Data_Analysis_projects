# Amazon Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing Amazon sales data using Microsoft Excel and Power BI to gain insights into sales performance, profitability, product trends, and customer behavior.

An interactive dashboard was developed to transform raw sales data into meaningful business insights and support data-driven decision-making.

## Tools & Technologies
- **Microsoft Excel:** Data Cleaning, Preparation, and Analysis.
- **Microsoft Power BI:** Data Visualization and Interactive Dashboard Development.

## Dashboard Pages

### 1. Executive Overview
Provides a high-level summary of business performance through key performance indicators (KPIs) and interactive visualizations.

### 2. Sales Analysis
Explores sales trends and performance to identify patterns and changes over time.

### 3. Product Analysis
Analyzes product performance and identifies important product-level sales insights.

### 4. Customer Analysis
Explores customer purchasing behavior and provides insights into customer performance.

## Key Features
- Interactive Power BI dashboards.
- Key Performance Indicators (KPIs).
- Sales and profitability analysis.
- Product performance analysis.
- Customer behavior analysis.
- Interactive filters and slicers.
- Data-driven business insights.

## Project Objectives
- Evaluate overall sales performance.
- Identify sales trends and patterns.
- Analyze product and customer performance.
- Monitor business profitability.
- Present insights through interactive visualizations.
