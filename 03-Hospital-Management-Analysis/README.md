# Hospital Management Data Analysis

## Project Overview
This project focuses on analyzing hospital data to gain insights into patient information, hospital staff, financial transactions, and overall hospital performance.

The project follows a data analysis workflow using Microsoft Excel, Python, SQL, and Power BI to prepare, process, analyze, and visualize data.

An interactive Power BI dashboard was developed to present key performance indicators (KPIs) and support better understanding of hospital operations.

## Tools & Technologies
- **Microsoft Excel:** Data Cleaning, Preparation, and Initial Analysis.
- **Python:** Data Processing, Analysis, and Exploratory Data Analysis (EDA).
- **SQL:** Database Management, Data Querying, and Analysis.
- **Power BI:** Data Visualization and Interactive Dashboard Development.

## Dashboard Pages

### 1. Patient Analysis
- Analyze patient information and distribution.
- Explore patient-related metrics.
- Examine Length of Stay (LOS).

### 2. Staff Analysis
- Explore hospital staff information.
- Analyze staff distribution and related metrics.

### 3. Payment Analysis
- Analyze hospital payments and billing information.
- Explore average bill amounts.
- Examine financial trends and payment patterns.
