# Sales Analysis Dashboard

## Project Overview
This project focuses on analyzing sales data using Microsoft Excel and Power BI to explore sales performance, product categories, customer behavior, and geographical trends.

An interactive Power BI dashboard was developed to present key business metrics and provide insights into sales and return quantities across different dimensions.

## Tools & Technologies
- Microsoft Excel – Data Preparation and Analysis
- Microsoft Power BI – Data Visualization and Dashboard Development

## Dashboard Features

### Key Performance Indicators (KPIs)
- Total Return Quantity: 3M
- Total Sales Profit: $10.2687M
- Total Order Quantity: 84K

### Data Analysis & Visualizations
- Return Quantity by Month
- Return Quantity by Country
- Revenue Distribution by Product Category
- Order Quantity by Age and Continent
- Total Sales by Year
- Product Performance Across Regions

### Interactive Filters
The dashboard includes interactive slicers to explore the data by:
- Year
- Country
- Month
- Product Category
- Product Name

## Project Objectives
- Analyze overall sales performance.
- Explore revenue and profit distribution.
- Identify product and geographical trends.
- Understand customer purchasing patterns across age groups and continents.
- Present business data through an interactive dashboard.
